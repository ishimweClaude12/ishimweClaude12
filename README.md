## About

I'm a full stack software engineer working across the web, mobile, and cloud. Day to day I build enterprise frontends in Angular, with micro-frontends, component-driven architecture, and clean state management using NgRx, Signals, and RxJS. On my own products I work in React, React Native/Expo, and TypeScript on top of REST and GraphQL APIs.

On the infrastructure side, I design AWS environments entirely as code with CloudFormation: multi-AZ networking, containerised workloads on ECS Fargate, blue/green deployments, and keyless CI/CD through GitHub OIDC.

I also build AI into how I work, not just into what I ship. I run large features through agentic workflows: planning, parallel build agents, parallel verification agents with Playwright, and a human-reviewed gate before anything merges.

What guides my work: I don't just want to know how a technology is used. I want to understand the architecture and trade-offs behind it.

## Engineering Principles

**Build for users.** Technology should solve a real problem and deliver a good experience.

**Keep it maintainable.** Code should be clear to the next developer who touches it. Small, focused diffs beat sweeping rewrites.

**Design for scale.** Applications and infrastructure need a clear path for growth.

**Diagnose before fixing.** Find the root cause first. Verify against the real code and API, not assumptions.

**Automate the checks.** Deterministic checks like types and linting belong in hooks. Judgment calls like access control and UI consistency get dedicated review.

**Understand the why.** Knowing the architecture and trade-offs matters more than knowing the syntax.

**Keep learning.** The field moves fast, so I keep exploring new tools and approaches.
