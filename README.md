## About

I'm a full stack software engineer focused on modern web architecture. My core strength is building component-driven applications with clean state management using NgRx, Signals, and RxJS, backed by GraphQL APIs and thoughtful design systems.

I also work across React and Next.js, backend services, and cloud infrastructure. My current focus is deepening my AWS and Infrastructure as Code skills, and exploring how AI can be built into real applications and developer workflows rather than treated as a bolt-on feature.

What guides my work: I don't just want to know how a technology is used. I want to understand the architecture and trade-offs behind it.

## Engineering Principles

**Build for users.** Technology should solve a real problem and deliver a good experience.

**Keep it maintainable.** Code should be clear to the next developer who touches it.

**Design for scale.** Applications and infrastructure need a clear path for growth.

**Understand the why.** Knowing the architecture and trade-offs matters more than knowing the syntax.

**Keep learning.** The field moves fast, so I keep exploring new tools and approaches.
